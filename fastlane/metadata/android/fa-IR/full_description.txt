JARVIS دستیار هوشمند اندروید است — «هی جارویس» بگو تا اپ‌ها باز شوند، صفحه خوانده شود، پیام ارسال شود و اتوماسیون‌ها اجرا شوند.

✦ دستیار صوتی فارسی و انگلیسی (Wake Word + STT + TTS)
✦ کنترل کامل گوشی با مجوز شما (Accessibility Service) — کلیک، تایپ، اسکرول، خواندن صفحه
✦ رابط کاربری Jetpack Compose + Material 3 با طراحی نئونی JARVIS
✦ Backend FastAPI با API سازگار با OpenAI (قابل اتصال به GPT-4o / Claude / Gemini / مدل محلی)
✦ اتوماسیون‌های برنامه‌ریزی‌شده (WorkManager) — «هر روز ۷ صبح آب‌وهوا رو بگو»
✦ حریم خصوصی: همه‌چیز روی دستگاه شما؛ بدون مجوز شما هیچ داده‌ای ارسال نمی‌شود

این نسخه مستقیماً توسط CI با Gradle واقعی ساخته شده است.
