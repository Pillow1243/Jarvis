**فوق‌العاده‌ترین دستیار هوشمند اندروید — قوی‌تر از OpenJarvis**

- 🎙️ دستیار صوتی Wake Word "هی جارویس"
- 📱 کنترل کامل گوشی (AccessibilityService)
- 🖼️ HUD شناور همیشه در دسترس
- 🧠 Backend FastAPI + OpenAI-compatible
- 🎨 Jetpack Compose Material 3 — رابط کاربری انفجاری
- ⚡ اتوماسیون نامحدود
- 🔔 Notification Listener + Quick Tile + Widget

## 📥 نصب
1. `jarvis-v2.0.0-debug.apk` را دانلود کن
2. نصب → مجوزها را تایید کن
3. بگو: "هی جارویس، سلام"

> APK های این ریلیز توسط GitHub Actions ساخته شده اند. برای build محلی: `./scripts/build-apk.sh`
